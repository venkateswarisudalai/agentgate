Click any scenario to spawn a synthetic agent that tries something risky against this control plane. The approval will appear on the Live tab. Approve or deny it, then come back to run the next one.
What just happened? Each scenario is a real synthetic agent calling the agentgate SDK (requireApproval()) against this server.
